# Project instructions

- Keep the app dependency-free and usable as a static GitHub Pages site.
- Treat the track geometry as meters and use SI units for physics calculations.
- Keep the user-facing speed in mph and acceleration in g.
- Validate the physics against the worked case in `spec.md` before adding optional features.
- Make focused commits at each assignment stage; do not combine stages.
- Update `prompts.md` with the prompts, decisions, and validation notes for each stage.
